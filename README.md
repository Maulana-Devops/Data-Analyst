## 📖 About This Repository

This repository documents my learning journey throughout a 12-week Industry Simulation Program in Data Analysis.

The main goal of this repository is not only to complete weekly assignments, but also to build a professional portfolio that demonstrates my analytical thinking, technical skills, documentation practices, and project workflow as a Junior Data Analyst.

Every project follows a real-world Data Analysis workflow:

Business Understanding

↓

Business Questions

↓

Data Collection

↓

Data Understanding

↓

Data Cleaning

↓

Exploratory Data Analysis (EDA)

↓

Visualization

↓

Insights

↓

Recommendations

↓

Documentation
