# 📖 About This Repository

This repository documents my work and learning progress throughout the **Industry Simulation Program in Data Analysis** organized by **PT Edusoft Center Teknologi**.

Unlike a typical learning repository, this repository is designed as a professional portfolio that demonstrates the complete workflow of a Junior Data Analyst, from understanding business problems to presenting insights and recommendations.

Throughout this program, every project follows real-world industry practices, including:

- Business Understanding
- Business Question Formulation
- Data Collection
- Data Understanding
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insight
- Reporting & Presentation
- Documentation
- Version Control using Git & GitHub

---

# 🎯 Program Objectives

By completing this Industry Simulation Program, I aim to:

- Perform end-to-end data analysis following industry standards.
- Solve business problems using data.
- Build analytical thinking and problem-solving skills.
- Communicate insights to both technical and non-technical audiences.
- Create professional documentation and reports.
- Develop a verifiable portfolio for future career opportunities.
