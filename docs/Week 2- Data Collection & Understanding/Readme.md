# 📊 Week 02 – Data Collection & Understanding

## 📖 Overview

This project documents my activities during **Week 02** of the **Industry Simulation Program – Data Analyst** at **PT Edusoft Center Teknologi**.

The focus of this week is to understand the importance of data collection, identify reliable data sources, evaluate potential datasets, and understand the structure and quality of a dataset before performing any data cleaning or analysis.

> **Note:** No data cleaning is performed during this week. Any issues found (such as missing values, duplicates, or incorrect data types) are only identified and documented for the next stage.

---

# 🎯 Learning Objectives

By the end of this week, I will be able to:

- Understand the concept of data collection in data analysis.
- Identify various public data sources.
- Evaluate datasets based on analysis requirements.
- Understand dataset structure and metadata.
- Create a Data Dictionary.
- Document findings before data cleaning.

# 📌 Daily Activities

## 📅 Day 01 – Dataset Discovery

### Objectives

- Learn about public data sources.
- Search for potential datasets.
- Compare candidate datasets.
- Select datasets suitable for further analysis.

### Deliverables

- Dataset comparison table.
- Initial dataset recommendations.

---

## 📅 Day 02 – Data Collection

### Objectives

- Select one primary dataset.
- Record dataset metadata.
- Document the source and licensing information.

### Deliverables

- Selected dataset.
- Dataset documentation.

---

## 📅 Day 03 – Data Understanding

### Objectives

- Explore dataset structure.
- Review rows, columns, and data types.
- Understand each variable.

### Deliverables

- Dataset summary.
- Initial exploration notebook.

---

## 📅 Day 04 – Data Profiling

### Objectives

- Identify potential data quality issues.
- Detect missing values.
- Detect duplicate records.
- Review data types.
- Identify potential outliers.

### Deliverables

- Data profiling report.
- List of identified issues.

> No corrections are made during this stage.

---

## 📅 Day 05 – Documentation

### Objectives

- Create a Data Dictionary.
- Summarize dataset characteristics.
- Prepare documentation for Week 03.

### Deliverables

- Data Dictionary.
- Dataset Understanding Report.
- Weekly summary.
