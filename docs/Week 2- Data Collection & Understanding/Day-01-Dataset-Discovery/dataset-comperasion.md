# 📊 Dataset Comparison

## Overview

Selecting the right dataset is the first step in every data analysis project. Instead of choosing the first available dataset, three different datasets were collected and evaluated based on their relevance, size, structure, and potential for business analysis.

This comparison documents the dataset selection process for the Industry Simulation Program.

---

# Evaluation Criteria

The following criteria were used during the evaluation:

| Criteria | Description |
|----------|-------------|
| Relevance | Suitable for business analysis and learning objectives |
| Data Size | Sufficient number of records for meaningful analysis |
| Feature Completeness | Contains useful variables for exploration |
| Data Quality | Well-structured and easy to understand |
| Analysis Potential | Suitable for EDA, visualization, SQL, dashboard, and storytelling |

---

# Final Decision

After comparing the three datasets, **100000 Sales Records** was selected as the primary dataset for this project.

The reasons include:

- Largest number of observations.
- Well-structured tabular data.
- Suitable for complete Data Analysis workflow.
- Supports descriptive statistics and visualization.
- Suitable for SQL, dashboard development, and storytelling.
- Scalable enough for future project expansion.

The remaining datasets will be retained for additional exercises and experiments in the **improvement** directory.
