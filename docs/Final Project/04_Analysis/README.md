# 04 Analysis

This folder contains the exploratory data analysis (EDA) deliverables.

## Structure

```
04_Analysis/
├── EDA_Notebook.ipynb         # Jupyter notebook with analysis code
├── EDA_Report.pdf             # PDF report with visualizations
```

## EDA Visualizations

The project's visualizations are delivered through:
- **EDA Report PDF** (`EDA_Report.pdf`) - contains charts and analysis
- **Excel Dashboard** (`06_Dashboard/Final_Dashboard.xlsx`) - interactive charts
- **Streamlit Dashboard** (`dashboard/app.py`) - interactive visualizations

Note: 10 visualization charts were generated locally for analysis but are not stored in the git repository. The primary visual deliverables are the PDF report and Excel dashboard.
