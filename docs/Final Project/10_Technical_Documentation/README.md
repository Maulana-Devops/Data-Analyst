# 10 Technical Documentation

This folder contains technical documentation for the Final Project.

## Structure

```
10_Technical_Documentation/
├── data-dictionary-and-methodology.md    # Column definitions & data dictionary
├── kpi-and-aggregation-contract.md       # KPI definitions & aggregation rules
├── dashboard-architecture-qa-and-reproducibility.md  # Dashboard architecture & QA
└── QA_Checklist.md                        # Quality assurance checklist
```

## Documentation Purpose

- **Data Dictionary:** Documents all 30 columns in the clean dataset, their types, and derivations
- **KPI Contract:** Defines how each metric is computed (revenue, AOV, cancellation, return, etc.)
- **Architecture:** Explains the dashboard design, testing methodology, and reproducibility
- **QA Checklist:** Verification checklist for deliverable compliance

All documents are maintained as Markdown for version control and traceability.
