# 🗺️ Data Analysis Learning Roadmap

This roadmap outlines my 12-week learning journey during the Industry Simulation Program as a Junior Data Analyst.

The objective is to build a strong foundation in Data Analysis while producing real-world portfolio projects following professional workflows.

---

# Learning Workflow

Every project follows the same workflow:

Business Understanding

↓

Business Questions

↓

Data Collection

↓

Data Understanding

↓

Data Cleaning

↓

Exploratory Data Analysis (EDA)

↓

Visualization

↓

Insights

↓

Recommendations

↓

Documentation

↓

GitHub Publication

---

# Weekly Roadmap

| Week | Topic | Mini Project | Deliverable |
|------|-------|-------------|-------------|
| 1 | Python Fundamentals | Python Exercises | Notebook |
| 2 | Data Collection | Dataset Discovery | Dataset Documentation |
| 3 | Data Understanding & EDA | Dataset Exploration | EDA Notebook |
| 4 | Data Cleaning | Cleaning Raw Dataset | Clean Dataset |
| 5 | Data Visualization | Charts & Graphs | Visualization Report |
| 6 | Descriptive Statistics | Statistical Analysis | EDA Report |
| 7 | SQL | SQL Query Practice | SQL Notebook |
| 8 | Business Analysis | Business Case | Business Insight |
| 9 | Dashboard | Interactive Dashboard | Dashboard Project |
| 10 | Data Storytelling | Analysis Report | Storytelling Report |
| 11 | Portfolio | GitHub Organization | Portfolio Repository |
| 12 | Capstone Project | End-to-End Analysis | Final Project |

---

# Learning Goals

By the end of this program I expect to be able to:

- Understand the complete Data Analysis workflow.
- Analyze structured datasets.
- Perform data cleaning.
- Conduct Exploratory Data Analysis (EDA).
- Build effective visualizations.
- Create dashboards.
- Produce business insights.
- Publish professional projects on GitHub.
