# Project 01 - SQL Fundamentals

## Overview

This project covers the fundamental concepts of SQL and Relational Database Management Systems (RDBMS), followed by basic SQL query exercises.

## Objectives

- Understand the basic concept of SQL.
- Understand the role of an RDBMS.
- Identify common RDBMS tools.
- Understand the basic structure of a relational database.
- Retrieve data from a table using `SELECT`.
- Select specific columns from a table.
- Limit the number of returned rows.

## Topics

### SQL & RDBMS

Introduction to Structured Query Language (SQL) and Relational Database Management Systems (RDBMS).

### RDBMS Tools

The material introduces:

- MySQL
- PostgreSQL
- Oracle DB
- Microsoft SQL Server
- SQLite
