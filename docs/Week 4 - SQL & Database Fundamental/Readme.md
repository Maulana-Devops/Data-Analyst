# Week 04 - SQL & Database Fundamentals

## Overview

Week 04 focuses on the fundamentals of SQL and Relational Database Management Systems (RDBMS).

The learning activities introduce the basic concepts of relational databases and SQL, followed by practical exercises using SQL queries to retrieve and rename data from database tables.

The main topics covered during this week are:

- SQL and RDBMS
- RDBMS tools
- RDBMS structure
- Selecting data from a table
- Selecting all columns
- Selecting specific columns
- Selecting multiple columns
- Limiting the number of rows
- Column aliases
- Table aliases
- Prefix with table names and aliases

---

## Learning Objectives

By the end of this week, I aim to understand the basic concepts of relational databases and be able to write basic SQL queries for retrieving and presenting data.

The main objectives are:

1. Understand the relationship between SQL and RDBMS.
2. Identify common RDBMS tools.
3. Understand the basic structure of a relational database.
4. Retrieve data from database tables using `SELECT`.
5. Select specific columns from a table.
6. Limit the number of returned rows.
7. Use aliases for columns.
8. Use aliases for tables.
9. Use prefixes to identify columns from a specific table.

## Topics

### 1. SQL & RDBMS

SQL stands for Structured Query Language and is used to communicate with relational database management systems.

RDBMS is a system used to create, update, and manage relational databases.
